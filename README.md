# MecoappsDocuments

This is the Mecoapps Documents portal, a high-fidelity web application for managing documents and presentations.

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Features

- Secure document management
- High-fidelity presentation viewer
- Admin dashboard for user and document control
- Integrated with Supabase for data and storage
